# Online Shop (Backend & Web UI)

Веб-приложение интернет-магазина, разработанное на **Spring Boot** с использованием **Spring Data JPA (Hibernate)**, **PostgreSQL** и шаблонизатора **Thymeleaf**.

---

## Технологический стек

* **Java 25** & **Spring Boot 4** (Spring Web MVC, Spring Data JPA, Spring Validation)
* **База данных:** PostgreSQL 15 + pgAdmin 4 (разворачиваются в Docker)
* **ORM:** Hibernate (автоматическая генерация схемы, управление связями, `@EntityGraph`)
* **Frontend:** HTML5 + Thymeleaf
* **Инструменты:** Maven, Lombok, Docker Compose

---

## Реализованный функционал

### 1. Управление пользователями (`/users`)
* Полноценный CRUD (просмотр списка, карточка пользователя, регистрация, редактирование, удаление).
* Серверная валидация форм с помощью Hibernate Validator (`@NotEmpty`, `@Size`, `@Email`).

### 2. Каталог товаров и поиск (`/products`)
* Связанные сущности `Product` и `Category` (`@ManyToOne(fetch = FetchType.LAZY)`).
* Автоматическое наполнение базы тестовыми категориями и товарами при первом запуске (`DataInitializer` через `CommandLineRunner`).
* Комбинированный поиск и фильтрация товаров:
    * по `ID`;
    * по названию (регистронезависимый поиск по подстроке);
    * по категории;
    * по диапазону цен (`minPrice` — `maxPrice`).

## Оптимизация работы с БД и Архитектура

* **Решение проблемы `N+1` запросов:** Для ленивой связи `Product -> Category` применён `@EntityGraph(attributePaths = {"category"})`, что позволяет загружать товары вместе с их категориями за один `JOIN`-запрос вместо серии отдельных `SELECT`.
* **Индексация:** На уровне сущности `Product` (`@Table(indexes = ...)`) созданы B-Tree индексы для ускорения фильтрации по колонкам `price`, `category_id` и `title`.
* **Паттерн Decorator (Декоратор):** Реализован `TimingProductServiceDecorator`, оборачивающий основной сервис поиска товаров `ProductServiceImpl` для замера и логирования времени выполнения SQL-запросов без изменения бизнес-логики.

## Инструкция по запуску

### 1. Запуск базы данных в Docker
Убедитесь, что запущен Docker Desktop, и выполните в корне проекта:
```bash
docker compose up -d
```
Будут подняты два контейнера:
* **PostgreSQL:** `localhost:5433` (БД: `online_market_db`, пользователь: `market_user`, пароль: `market_password`)
* **pgAdmin 4:** `http://localhost:8080`

### 2. Запуск приложения
Запустите главный класс `OnlineShopApplication` из IDE или через Maven:
```bash
./mvnw spring-boot:run
```

### 3. Основные страницы в браузере
* **Каталог товаров и поиск:** `http://localhost:8081/products`
* **Список пользователей:** `http://localhost:8081/users`
